Day 1 – Learning How to Use and Collaborate on GitHub

Today marks the first step of my website creation journey. Instead of jumping straight into coding, I spent the day figuring out how to use GitHub and understanding how collaboration works. At first, it felt overwhelming,there were repositories, branches, commits, and pull requests, but as I explored more, everything slowly started to make sense. I learned how to create a repository, push my changes, and pull updates from collaborators. This day helped me realize that building a website is not just about writing code, but also about managing versions and working with others efficiently. By the end of the day, I felt more confident knowing that I could now collaborate properly and keep my work organized.

Day 2 – Creating the Basic HTML Structure

On the second day, I finally started working on the actual website. I focused on building the basic structure of my HTML file. I created the main layout, including the head and body sections, and began organizing where each part of the content would go. This step may seem simple, but it felt rewarding because I could finally see the foundation of my website taking shape. I learned how important structure is before adding designs or advanced features. Today was all about setting up a clean and understandable layout that I can improve on in the following days.

Day 3 – Polishing Content and Starting the Design

Today, February 26, I worked on improving and polishing the content of my website. I revised the text, made sure everything was clear, and adjusted the layout to make it more presentable. After that, I started experimenting with the design by thinking about colors, fonts, and adding images as a design. This part made the website feel more personal and alive. Seeing my content combined with early design choices made me excited to continue improving it.
